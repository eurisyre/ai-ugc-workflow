# AI UGC Workflow

A simple AI-powered workflow for creating UGC-style product content.

## Purpose
This project documents a repeatable system for generating product photos, video prompts, hooks, and CTA scripts for social media campaigns.

## Features
- Product content planning
- UGC photo shot list
- AI image prompt structure
- I2V video prompt structure
- Hook and CTA framework

## Use Case
Useful for TikTok Shop, Shopee, Instagram Reels, and short-form content production.

## Tools
- ChatGPT
- AI image generator
- Kling / Veo / Seedance
- Canva / CapCut
